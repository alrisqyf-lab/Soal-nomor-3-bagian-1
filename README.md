Mengambil Input Jumlah Siswa: Menanyakan berapa banyak siswa yang akan dihitung nilainya.

Validasi: Memastikan jumlah siswa yang dimasukkan valid (lebih dari nol).

Pengumpulan Nilai: Menggunakan perulangan (for loop) untuk meminta dan menjumlahkan nilai setiap siswa satu per satu.

Perhitungan Rata-Rata: Membagi total nilai dengan jumlah siswa.

Menampilkan Hasil: Menyajikan total nilai dan rata-rata kelas kepada pengguna.
